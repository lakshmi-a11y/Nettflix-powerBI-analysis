# NETFLIX SUBSCRIBER & VIEWING ANALYSIS
![Dash board Image](Dash board%20Image.png)
## PROJECT OVERVIEW

The Netflix Subscriber & Viewing Analytics is an interactive Power BI project designed to analyze subscriber behavior, viewing patterns, content preferences, and subscription details.

The dashboard presents key insights through KPI cards, charts, and interactive filters, making complex data simple, clear, and easy to understand.

## OBJECTIVES

- Analyze subscriber behavior
- Understand viewing patterns
- Identify content preferences
- 
- Analyze subscription details
- Identify important trends in subscriber data

## TOOLS & TECHNOLOGIES

- Power BI
- Excel

## KEY ANALYSIS

- Subscriber Analysis
- Viewing Pattern Analysis
- Genre & Rating Analysis
- Revenue & Subscription Analysis

## DASHBOARD FEATURES

- KPI Cards
- Interactive Charts
- Interactive Filters / Slicers
- Subscriber Trends
- Viewing Pattern Analysis
- Subscription Analysis

## CONCLUSION

This project provides a clear overview of subscribers, spending, watch hours, movies, and user preferences. The interactive dashboard helps understand viewing patterns and customer behavior through charts, KPI cards, and filters.
